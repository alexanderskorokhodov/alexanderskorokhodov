# Public portfolio — agent instructions

This repository is Alexander Skorokhodov's public engineering portfolio for prospective customers and technical reviewers. It is not a commercial pilot source-code repository or an internal project tracker.

- Read [PUBLICATION_POLICY.md](PUBLICATION_POLICY.md) before preparing or changing public content.
- Reuse [projects/README.md](projects/README.md), [notes/README.md](notes/README.md) and [research/README.md](research/README.md) as indexes. Do not duplicate full case studies maintained in other public repositories.
- Use [the case-study template](templates/engineering-case-study.md) for new case studies. Lead with the workflow, then evidence, design decisions, failure handling and limitations.
- Use only already-public facts or material specifically cleared by the owner. Distinguish historical reported metrics from independently measured results; prototypes, proposals and deployments are different states.
- Never import private code, client records, credentials, raw conversations, unpublished notes, proprietary implementation details or internal sales plans. Do not link to private sources.
- Unapproved drafts belong outside this public repository, not in a public branch, issue, PR or Git history. Owner approval is required for new substantive public disclosures and outbound communications.
- Before publishing, verify source links, status, permissions, attribution, asset redaction and consistency with the main README. Preserve existing material unless removal is authorized.
- Keep the portfolio concise. No automatic publishing, paid infrastructure, GitHub Actions or new trackers by default.
